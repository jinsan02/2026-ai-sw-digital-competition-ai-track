### 반대로, 근거가 확실해서 강하게 말해도 되는 것

1. **검증 기준 자체를 폐기한 판단** — 내부 게이트가 실제 지표와 반복적으로 어긋나자 기준을 버렸다. (`finals/03` §1, `ref_슬랙로그:394`)
2. **내부 지표 편향을 숫자로 측정** — fixed +0.009 / focal +0.013 / 로컬 KD +0.012 / 시드 ±0.011. (`CLAUDE.md:29~32`)
3. **자기 착시를 스스로 잡아낸 사례** — A0/A1 +0.002 → 재생성 후 +0.0008로 정정하고 축 기각. (`finals/03` §3)
4. **인프라 버그 추적** — 캐시 키 seed 누락으로 게이트 0.31 붕괴 → 원인 규명·3머신 패치. (`finals/03` §3)
5. **제출팩 바이트 단위 직접 검증** — 1,005,612,893B 일치·CRC·순정 확인. (`finals/12` #9)
6. **282행 실험 원장 운영** — 레시피·split·점수·아티팩트 경로·판정을 표준 스키마로 축적. (`results.csv`)
