## 2. 챔피언 계열 공통 레시피 (검증된 base CLI)

```bash
python train_transformer.py \
  --base-model naver-hyperclovax/HyperCLOVAX-SEED-Text-Instruct-0.5B \
  --lr 2e-5 --device cuda --split session --serializer current_v1 \
  --max-length 384 --epochs 3 --batch-size 16 --grad-accum-steps 1 \
  --eval-batch-size 64 --gradient-checkpointing \
  --class-weight-power 0.5 --label-smoothing 0.02 --loss focal --focal-gamma 2.0 \
  --replay-mode last1 --max-replay-samples 10000 --replay-sample-weight 0.5 \
  --distill-logits <teacher>.pt --distill-alpha 0.5 --distill-alpha-weak 0.7 --distill-temp 3.0 \
  --consensus-reliability 20260710_m7_m8_v6_oof_consensus.pt \
  --consensus-backbone-weights 0,0.25,0.75,1 \
  --tokenize-batch-size 1024 --seed <SEED> --no-research-log --save-fp16 \
  --final-model --final-only
```
- **amw4 (챔피언)**: 위 base CLI + 아래 6개 플래그 (준현 확정 CLI — 품질 변수는 AM 3개뿐, AMP 3개는 안정화):
  ```
  --action-margin-kd-target-grad-ratio 0.10 --action-margin-kd-topk 3 --action-margin-kd-label-scope weak4
  --amp-init-scale 64 --amp-growth-interval 1000000 --require-zero-amp-skips
  ```
  `<teacher>` = `m8_qwen35_refit_train70k_fp16.pt` (원본 M8 — trioT 아님). 구현: `train_transformer.py` 커밋 `070338a` (`action_margin_kd_loss` 외 2함수). 플랜 JSON: `colab/action_margin_weak4_refit_{s7070_lane_a,lane_b,s909_lane_c}_plan.json`
- 양자화: `quantize_checkpoint.py quantize --input model.safetensors --output model.int8.safetensors` / int4는 `quantize_int4.py` (group128)
