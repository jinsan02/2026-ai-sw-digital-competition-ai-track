## QnA 예상 질문 20 + 답변 스케치

**[모델/기법]**
1. **왜 0.5B 모델인가? 더 큰 모델 안 썼나?** → 시간예산 산식(forward 0.95, 10분 제한)상 단독 ≤0.6B. 0.8B ep3는 실측 시간초과. 대신 큰 모델(9B까지)은 **교사로만** 사용 — 대회 취지(경량 의사결정)와 일치.
2. **KD 교사를 어떻게 골랐나?** → train 일치율 역상관 법칙 (슬라이드 6). 사전 게이트: 일치율 ~0.8 이상적, 0.9+ 기각.
3. **자기증류가 왜 마지막에야 가능했나?** → 트리오(0.7966)가 생기고서야 "배포 계열과 동족 + 엄격히 더 강한" 교사가 존재하게 됨.
4. **앙상블 3개 모델의 다양성은 어디서 오나?** → 시드+레시피 변형. 단, 시드차=노이즈 실증했으므로 다양성 본질은 KD 교사·조건부α 변형. 이질 아키텍처(mbert/xlm-r)는 실측 음성으로 기각.
5. **룰 기반 후처리는 오버피팅 아닌가?** → 5-fold×2시드 전부 rescue>harm + 배포 main OOF 재검증(transfer gate) + Public 단조 상승으로 3중 확인. in-sample 튜닝 룰은 실제로 실패(0.7794)해서 폐기한 경험 있음.
6. **Macro-F1 최적화를 위해 뭘 했나?** → focal γ2.0 + class-weight-power 0.5 + Weak4(희소 4클래스) 조건부 α·action-margin — 희소 클래스에 학습·증류·후처리 3층 개입.

**[한계/분석]**
7. **점수 상한이 어디라고 보나?** → 탐색4 클래스는 Bayes 상한 0.570 증명(동일 컨텍스트 93% 라벨 갈림). 남은 이득은 모델 본체 외 영역이 아니라 데이터 노이즈 밖 클래스 정밀도.
8. **1위와의 차이는 뭐였을 것 같나?** → 0.0010 차이. 우리 기각축 밖의 축(예: 더 강한 교사 사다리, 앙상블 규모) 또는 동일 기법의 시드 운. 재현 관점에선 유의미한 격차 아님 → 검증 문화로 답변.
9. **Private가 Public 스냅샷인데 오버피팅 리스크는?** → 테스트 100%가 Public이라 리더보드 낚시 위험 자체가 구조적으로 큼 → 우리는 내부 OOF 스크린 통과분만 제출하는 원칙으로 대응.
10. **실패한 실험 중 가장 아까운 것은?** → trajectory 조밀화(A1): fold0 +0.0008 / fold1 −0.0016으로 기각. 삭제된 베이스라인을 재생성해서까지 판정 무결성 지킴.

**[엔지니어링/재현]**
11. **양자화로 성능 안 떨어졌나?** → int8 argmax 충실도 99.6% (Δ≈−0.0002). int4는 main엔 열화(94.5%)라 멤버만.
12. **추론 7:15의 병목은?** → forward 95%. 동적 패딩이라 len캡 무효 — 토큰 수 자체가 비용. 저마진 라우팅으로 2·3모델 통과를 34.1%로 제한 (준현 실측; @1.25=39.7%, @0.75=~28.5%).
13. **재현성 보장은?** → seed 고정 + 레시피 CLI 전량 로그 + 캐시 시드버그 사후 수정 사례(발견→원인 규명→3머신 패치) 자체가 재현성 관리 증거.
14. **왜 PDF 팩이 1005MB나 되나?** → 0.5B×3 (int8 568 + int4 292×2). 1GiB 한도 실측 확인 후 안전 마진 운영.
15. **팀 역할 분담은?** → 진산(팀장·검증/실험 하니스·인프라)·원주(데이터 분석·blind-spot 감사)·준현(모델 고도화·KD 레인)·태연(추론 코드·제출 관리). 레인 분리 + Slack 단일 창구.

**[운영]**
16. **하루 10회 제출을 어떻게 썼나?** → 판독용 단독팩을 끼워 기여 분해(예: trio-KD 단독 0.7937 vs main-swap 0.7972 = 프레임워크 기여 +0.0035 분리).
17. **마감 직전 제출 전략은?** → 최고점 자동선택 규정 활용 — 막판 margin 0.75 도박(0.7974)도 무손실. 규정 이해가 곧 전략.
18. **GPU 자원은?** → 학교 A100 + 개인 4070/3060 + Colab. 유료 API 미사용.
19. **외부 데이터는?** → 미사용. 증강 실험(구조보존 익명화 114k)은 자체 변환이었고 음성이라 폐기.
20. **본선 이후 개선 방향은?** → ① 2세대 자기증류 반복(수렴까지) ② Weak4 전용 보조헤드 ③ 세션 그래프 구조 활용(예선 중 기각됐지만 시간 제약 원인) — backlog 문서 보유.
