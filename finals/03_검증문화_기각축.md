# 03 — 검증 문화 & 기각된 축 (차별화 스토리)

> 전문가 심사에서 "왜 이 팀이 엔지니어링을 잘하는가"를 증명하는 자료.
> 핵심 메시지: **"우리는 되는 것만 쌓은 게 아니라, 안 되는 것을 빠르고 싸게 죽였다."**

---

## 1. 판정 프로토콜 (모든 실험에 공통 적용)

1. **단일변수 원칙** — 레시피에서 정확히 1개만 바꿔 A/B (seed·fold·데이터 고정)
2. **내부 스크린 우선** — session-OOF 3-fold held-out에서 fold-safe 판정 후에만 Public 슬롯 사용
3. **판정 기준 명문화** — "한 fold라도 음성이면 기각" / "5-fold 전부 rescue>harm만 룰 승격"
4. **배포 표면 재검증(s202 transfer gate)** — 개발 시드에서 이긴 레버도 배포 main의 OOF에서 재측정
5. **KD는 매치드시드 Public로만** — 로컬 KD 스크린은 fold-교사 val 간접누수로 +0.012 인플레 실증 → 내부 수치 불신

## 2. 기각된 축 전체 목록 (음성 결과 = 자산)

| 축 | 판정 근거 | 결론 |
|---|---|---|
| **혼동클래스 공략** (탐색4: read/grep/list/glob) | 동일 정규화 컨텍스트의 93%에서 라벨 갈림, **Bayes 상한 0.570 ≈ 현 모델 0.58** — 5중 증거 | aleatoric 노이즈. 모델 본체 개선 외 잔여 이득 없음 |
| **직렬화 변형** (v5/v6/state_v2) | v5 −0.0047, v1⊕v5 블렌드 오류중첩 85% | current_v1 확정, 직렬화 다양성 없음 |
| **인코더 라인** (XLM-R large, kf-deberta) | large 단독 0.7733 < Qwen 0.7807, 앙상블 0.7720 역효과 | 디코더 0.5~0.6B로 전환 |
| **이질 멤버** (mbert, xlm-r-large) | 배포 라우팅(margin<1.25) 재현서 전 변형 음성(−0.001~−0.005), 전 셀 harm>rescue — "m7의 KD-흡수 패턴이 인코더 계열에도 적용" | 이질 멤버 축 완전 폐쇄 |
| **동계열 KD 교사** (HCX-1.5B) | 홀드아웃 0.7766으로 강했는데 Public −0.0147 | "학생이 모르는 걸 아는가"가 기준 (02-① 법칙) |
| **거대 교사** (Qwen3.5-9B) | train 일치율 0.9428 → 이득 ±0.000 | 원핫 붕괴, 이견 없음 |
| **trajectory/replay 조밀화** (A0/A1, replay last1→all) | 2-fold 클린 판정: f0 +0.0008 / f1 **−0.0016** → 평균 −0.0004 | 기각. 삭제된 베이스라인 재생성까지 해서 검증 무결성 유지 |
| **α/T 비율 탐색** | α0.7/T2 = α0.5/T3 완전 동점 (0.789 수렴) | 무차별 영역, 추가 탐색 금지 |
| **int4 전면 양자화** | argmax 94.5% (게이트 99.5%) | int8 유지, 멤버만 int4 |
| **test-time 자가학습/tta 계열** | 5-fold 시뮬 전 폴드 음성 | 기각 |
| **시드 리롤(멤버 시드 낚시)** | 20k 트리오 점수표: 2k↔20k 순위 완전 재셔플 = **시드차 = 순수 노이즈**; c0a8_swap 소수 10자리 동률로 재확인 | "시드 복권"은 최후수단으로 강등 → 대신 main-swap best-of-N(검증된 축의 인스턴스 생산)으로 전환 |
| **test 세션 체인 누수** | chainprobe 제출 = 기준선과 완전 동점 → train↔test 세션 겹침 0 | 누수 없음 확인, 정공법 확정 |

## 3.5 데이터 품질·강건성 감사 (원주·태연 트랙 — 발표 "완성도" 재료)

- **Confident Learning 라벨오류 감사 (원주)**: champ OOF 3-fold로 cleanlab 방법론 적용 → 극단 확신 오류 60건(0.086%) 중 **계통적 라벨 오류 21건 특정** (예: "create X? no wait exists" 문맥의 plan_task↔write_file 3건 패턴). apply_patch↔edit_file 39건은 R1b/R1h 룰이 이미 흡수 — 룰과 데이터 감사가 상호 검증.
- **sim/au 도메인 분리 분석 (원주)**: train = sim 92.8% / au 7.2%, au는 err 0.051로 오히려 쉬움, test 공개샘플 100% sim → aleatoric 상한은 sim 기준으로 산정해야 함을 확정. 도메인 시프트 리스크 소거.
- **직렬화 표현 강건성 probe (태연)**: 의미 보존 변형 2종(args 키 순서 역전·공백 정규화)을 최악 표본 500행(margin<1.0 & 탐색4)에 주입 — **실제 텍스트가 바뀐 164행에서 argmax flip 0건** → "표현 섭동에 강건" 서사 확보 + TTA(변형 로짓 평균) 카드 근거 있게 기각. read_bias(−0.14) 반증도 전 구간 스윕으로 독립 재확인 (pooled 양수 지점 0개).

## 4. 협업 검증 사례 (팀워크 어필)

- **원주 "R1d/R1e 폴드 불안정" 신호** → 5-fold×교차시드 전수 팩트체크 → 원주 집계의 harm 정의(중립 플립 포함)가 원인, 정확 집계로는 R1d 5폴드 0-harm — **소표본 회계 착시**로 판정, 룰 유지. 반박이 아니라 검증으로 합의.
- **준현 Lane B(replay 메타데이터)** 음성 결과 ↔ 우리 A1 클린 재현 음성 — 서로 다른 구현으로 **같은 부호 재현** → 축 종결 합의.
- 마지막 밤: 진산 레인(A0/A1 검증, KD 시드 생산) / 준현 레인(trio-KD, Weak4-AM) 분리 운영, Slack으로 제출 창구 단일화.
