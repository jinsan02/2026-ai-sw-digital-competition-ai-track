# subagents.md — 서브 에이전트 / 컨텍스트 위임 (DACON)

## 언제 분할하나

| 조건 | 액션 |
|------|------|
| 독립 도메인 2개 이상 (예: 데탑 학습 모니터링 + 로컬 패키징) | 병렬 처리 |
| 대용량 로그/데이터 탐색 | Explore 서브에이전트에 위임 후 결론만 회수 |
| 컨텍스트 과다 | 요약 핸드오프 후 계속 |

## DACON 특화 위임 패턴

- **원격 학습 모니터링**: `ssh desktop-3060`로 로그·metrics만 회수, 원문 로그 통짜 회수 금지(토큰).
- **실험 스크린**: fixed split 결과만 먼저 회수 → 유망하면 OOF. (large는 6h/fold이므로 남발 금지)
- **팀 컨텍스트 수집**: Slack/Notion MCP는 별도로 수집해 요약만 메인에 전달.

## 핸드오프 형식

```
## 완료 보고
- 담당: [범위]
- 산출: [파일/로짓/점수]
- 판정: fixed/OOF 수치 + 게이트 통과 여부
- 다음 주의: [블렌딩 split 정렬 등]
```

> 원칙: 점수 비교는 **같은 하니스·같은 split**에서만. 코드베이스 간 비교 금지.
